# Arcade Mania

Arcade Mania is a 2D browser-based platform game developed using HTML, CSS, JavaScript and HTML5 Canvas.

## 🎮 About the Game

The player selects one of two characters:

- Vinnie – Jungle Theme
- Benny – Desert Theme

The objective is to collect all 6 energy items, avoid obstacles, use platforms to progress through the level, and finally reach the portal.

## ✨ Features

- Character selection
- Two different game themes
- Keyboard-based player movement
- Jumping and gravity
- Static platforms
- Moving platforms
- Energy collection system
- Thorn obstacles
- Life system with 3 lives
- Character animations
- Win and Game Over states
- Sound effects
- Exit button
- Responsive game canvas

## 🕹️ Controls

| Key         | Action                      |
| ----------- | --------------------------- |
| Left Arrow  | Move left                   |
| Right Arrow | Move right                  |
| Space       | Jump                        |
| R           | Restart after Game Over/Win |

## 🎯 Game Objective

1. Select a character.
2. Start the game.
3. Move through the level using the platforms.
4. Collect all 6 energy items.
5. Avoid thorns and falling from the level.
6. Reach the portal after collecting all energies.
7. Complete the level.

## 🛠️ Technologies Used
